# Scratch

Per-session working notes. One file per session: `<date>-<topic>.md`.

- Freeform: commands tried, dead ends, API quirks, numbers, half-ideas.
- At session end, distill anything durable into `HANDOVER.md` (status, decisions, gotchas).
- These files are disposable — delete or leave them once their thread ships. Never treat them as source of truth; `HANDOVER.md` is.
